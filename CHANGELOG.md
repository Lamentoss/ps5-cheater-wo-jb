# Changelog

## 0.1.0

First release.

- Web app with a four-step connection guide, cheat cart, game library and built-in docs
- One Remote Play connection per run: connect once, type every cheat, wait, disconnect once
- Network discovery that works with a VPN on the default route
- Open game check using a real frame from the console
- SQLite library with JSON pack import and export
- MCP server over HTTP and stdio with 10 tools
- GTA: Vice City - The Definitive Edition pack with 52 cheats
- macOS Apple silicon app
